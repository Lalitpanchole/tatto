# 06 - UI Design System & Aesthetic Tokens

## 1. Design Philosophy
The Tattooplatz digital experience features a modern, high-contrast **punk-chic & curved dark/light aesthetic**. It emphasizes rich typography, vibrant neon pink accents, smooth glassmorphism modals, and micro-animations.

---

## 2. Color Palette Tokens

| Token Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary White** | `#FFFFFF` | Core Backgrounds, Card Container Fill, Crisp Text |
| **Primary Black** | `#000000` | High-Contrast Typography, Buttons, Structural Cards |
| **Neon Pink Accent** | `#FF66C4` | Primary CTAs, Active Stepper Nodes, Price Highlights, Hover Glow |
| **Pastel Pink Highlight** | `#F4B6DE` | Secondary Badges, Active Sub-elements, Soft Glow Borders |
| **Dark Dark Container** | `#111111` / `#18181B` | Contact Banner, Blocked Slot Indicators, Dark Mode Elements |

---

## 3. Typography & Styling Rules
- **Header Font:** High-impact uppercase sans-serif (`Outfit`, `Inter`, `Montserrat`).
- **Body Font:** Clean, readable geometric sans-serif.
- **Border Curves:** Rounded containers (`rounded-xl`, `rounded-2xl`) and pilled buttons (`rounded-full`).
- **Hover Effects:** Smooth scale transformations (`hover:scale-105`), pink glow shadows (`hover:shadow-[0_4px_12px_rgba(255,102,196,0.3)]`).
